# AutomotiveGUI 验收标准自述

## 1. 技术路径声明

选择章程 §4.4 的 **C：UIAutomator 控件树 + 视觉兜底**。

`perception/capture.py` 同轮采集截图与 XML；

`core/graph.py` 的 `router` 在候选足够且目标未被裁剪遗漏时走 tree，模型从候选里选 `node_ref`；

XML 不可用、候选不足、目标遗漏或 tree 决策无效时走 VLM，模型依据截图给出位置。

VLM 图片坐标由执行层换算成设备坐标。

## 2. 交付标准自述
- 任务框架执行稳定，有完善的反思、防重、回退、降级、守卫能力。缺点就是流程略显繁琐
- 支持跨应用的复杂指令，但是暂未完整适配车机app
